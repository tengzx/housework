快捷指令远端管理接口文档

用于把记录页的快捷指令列表从本地 UserDefaults 迁移到远端。覆盖列表拉取、新增、修改、删除、排序，以及和当前进行中记录的关系。

一、通用约定

服务器地址：http://100.67.64.11:8081/。本文件以下路径默认基于 /api/mobile，完整地址示例为 http://100.67.64.11:8081/api/mobile/shortcut-tasks。

请求格式：Content-Type: application/json，返回 application/json。

ID：快捷指令 ID 建议由后端生成稳定字符串，例如 task_01J...。App 端可以映射到本地 UUID，但远端应以字符串 ID 为准。

图标：symbolName 使用 SF Symbols 名称，例如 book、dumbbell.fill、briefcase。

颜色：colorHex 使用不带井号的 6 位十六进制，例如 FF7847。返回带 # 也可以，但 App 侧会统一清洗。

排序：sortOrder 越小越靠前。后端返回列表时应已按 sortOrder ASC, createdAt ASC 排序。

二、最小交付接口

要支持远端新增、删除、管理，至少需要以下 5 个接口：

  • GET /api/mobile/shortcut-tasks：拉取快捷指令列表
  • POST /api/mobile/shortcut-tasks：新增快捷指令
  • PATCH /api/mobile/shortcut-tasks/{id}：修改名称、图标、颜色、启用状态
  • DELETE /api/mobile/shortcut-tasks/{id}：删除快捷指令
  • PUT /api/mobile/shortcut-tasks/reorder：保存排序

三、数据模型

字段类型必填说明
idstring返回必填快捷指令唯一 ID
namestring是显示名称，例如 写代码
symbolNamestring是SF Symbols 图标名
colorHexstring是主题色，例如 FF7847
sortOrdernumber是列表排序值
isEnabledboolean否默认 true。软删除或临时隐藏时可设为 false
createdAtstring返回建议ISO 8601，带时区
updatedAtstring返回建议ISO 8601，带时区

四、接口详情

GET /api/mobile/shortcut-tasks

获取当前用户的快捷指令列表。App 启动记录页、从后台回到前台、下拉刷新时调用。

返回示例

{
  "tasks": [
    {
      "id": "task_coding",
      "name": "写代码",
      "symbolName": "chevron.left.forwardslash.chevron.right",
      "colorHex": "FF7847",
      "sortOrder": 10,
      "isEnabled": true,
      "createdAt": "2026-06-25T10:00:00+03:00",
      "updatedAt": "2026-06-25T10:00:00+03:00"
    },
    {
      "id": "task_reading",
      "name": "阅读",
      "symbolName": "book",
      "colorHex": "FF7847",
      "sortOrder": 20,
      "isEnabled": true,
      "createdAt": "2026-06-25T10:00:00+03:00",
      "updatedAt": "2026-06-25T10:00:00+03:00"
    }
  ]
}

兼容建议：如果还没有远端数据，后端可以返回空数组，App 会使用内置默认指令并在用户第一次新增/修改时同步到远端。

POST /api/mobile/shortcut-tasks

新增快捷指令。用户在“新增快捷指令”弹窗中输入名称并选择图标后调用。

请求示例

{
  "name": "写日记",
  "symbolName": "pencil",
  "colorHex": "FF7847"
}

返回示例

{
  "task": {
    "id": "task_01J1ABCDE",
    "name": "写日记",
    "symbolName": "pencil",
    "colorHex": "FF7847",
    "sortOrder": 70,
    "isEnabled": true,
    "createdAt": "2026-06-25T13:45:00+03:00",
    "updatedAt": "2026-06-25T13:45:00+03:00"
  }
}
校验建议
名称为空返回 400 SHORTCUT_TASK_NAME_REQUIRED
名称过长建议限制 1-30 个字符
同名可以允许；如果不允许，返回 409 SHORTCUT_TASK_DUPLICATE_NAME
图标非法建议接受任意字符串，前端负责展示兜底图标

PATCH /api/mobile/shortcut-tasks/{id}

修改快捷指令。用于后续管理页里重命名、换图标、换颜色、启用/隐藏。

请求示例

{
  "name": "深度写作",
  "symbolName": "pencil.and.outline",
  "colorHex": "6C5CE7",
  "isEnabled": true
}

所有字段都是可选字段，后端只更新请求中出现的字段。

返回示例

{
  "task": {
    "id": "task_01J1ABCDE",
    "name": "深度写作",
    "symbolName": "pencil.and.outline",
    "colorHex": "6C5CE7",
    "sortOrder": 70,
    "isEnabled": true,
    "createdAt": "2026-06-25T13:45:00+03:00",
    "updatedAt": "2026-06-25T13:50:00+03:00"
  }
}

DELETE /api/mobile/shortcut-tasks/{id}

删除快捷指令。当前 App 点击管理模式下的减号时调用。

返回示例

{
  "ok": true
}

删除进行中的快捷指令：如果被删除的 task 正在进行中，建议后端同时结束当前 time entry，并返回 endedRunningEntry: true。

{
  "ok": true,
  "endedRunningEntry": true
}

如果后端不自动结束，应返回 409 SHORTCUT_TASK_RUNNING，App 再调用现有 POST /api/mobile/time-entries/end。

PUT /api/mobile/shortcut-tasks/reorder

保存快捷指令排序。用户拖动排序后一次性提交完整顺序。

请求示例

{
  "taskIds": [
    "task_coding",
    "task_reading",
    "task_fitness",
    "task_meeting"
  ]
}

返回示例

{
  "tasks": [
    {
      "id": "task_coding",
      "name": "写代码",
      "symbolName": "chevron.left.forwardslash.chevron.right",
      "colorHex": "FF7847",
      "sortOrder": 10,
      "isEnabled": true,
      "createdAt": "2026-06-25T10:00:00+03:00",
      "updatedAt": "2026-06-25T14:00:00+03:00"
    }
  ]
}

五、和开始/结束记录的关系

当前 App 已经使用以下现有接口同步“正在做什么”：

  • GET /api/mobile/time-entries/running：获取进行中记录
  • POST /api/mobile/time-entries/start：开始记录
  • POST /api/mobile/time-entries/end：结束记录

建议把 POST /api/mobile/time-entries/start 扩展为优先接收 taskId，同时继续兼容旧的 taskName。

推荐开始请求

{
  "taskId": "task_coding",
  "taskName": "写代码",
  "startedAt": "2026-06-25T13:39:20+03:00",
  "source": "mobile",
  "note": null
}

推荐 running 返回

{
  "id": 1196,
  "taskId": "task_coding",
  "taskName": "写代码",
  "status": "running",
  "startedAt": "2026-06-25T13:39:20+03:00",
  "endedAt": null,
  "durationSeconds": 20,
  "source": "mobile",
  "note": null
}

六、错误返回建议

建议所有错误都使用统一结构，方便 App 显示中文提示或做分支处理。

{
  "success": false,
  "error": "快捷指令不存在",
  "code": "SHORTCUT_TASK_NOT_FOUND",
  "details": {
    "taskId": "task_missing"
  }
}
HTTP 状态code说明
400SHORTCUT_TASK_NAME_REQUIRED名称为空
400SHORTCUT_TASK_INVALID_COLOR颜色不是合法十六进制
404SHORTCUT_TASK_NOT_FOUND快捷指令不存在或不属于当前用户
409SHORTCUT_TASK_RUNNING删除的快捷指令正在进行中，且后端没有自动结束
409SHORTCUT_TASK_DUPLICATE_NAME后端不允许同名时返回

七、后端实现备注

  • 快捷指令属于用户级配置，建议按用户隔离；如果当前没有登录系统，可以先按设备或固定默认用户隔离。
  • 删除建议优先做软删除，保留历史 time entry 中的 taskName 快照，避免旧记录无法展示。
  • 开始记录时建议同时保存 taskId 和 taskName。名称以后被修改时，历史记录仍能保留当时的展示名。
  • 如果 App 首次接入远端，后端可以预置默认 6 个快捷指令：写代码、阅读、健身、开会、吃饭、休息。
